# 🚪 Portaria Inteligente - TechZone

Sistema simples de controle de acesso desenvolvido em **HTML e JavaScript puro**, simulando uma portaria digital.

---

## 📌 Descrição

Este projeto verifica se um colaborador está autorizado a entrar com base em:

- ✔ Nome cadastrado no sistema  
- ✔ Horário permitido de acesso  

O sistema retorna mensagens informando se o acesso foi permitido ou negado.

---

## 🛠 Tecnologias Utilizadas

- HTML5
- JavaScript
